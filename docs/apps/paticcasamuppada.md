# Приложение `paticcasamuppada` — тренажёр 12 звеньев

Тренажёр для запоминания цепи взаимозависимого возникновения (paṭiccasamuppāda) к публикациям
`vzaimozavisimoe-vozniknovenie` (RU) и `patitchasamupbat` (TH). Встраивается обогатителем «Приложение»:

```html
<div data-widget="app" data-app="paticcasamuppada"></div>
```

Пометка в черновике: `[приложение: paticcasamuppada]`. Как устроен обогатитель — `docs/for-researchers/ru.md`,
раздел «Обогатители публикаций» (№ 16).

## Файлы

`publications/apps/paticcasamuppada/`:

| Файл | Что это |
|---|---|
| `app.json` | имя, версия, название и описание карточки на двух языках, текст «без JavaScript» |
| `app.js` | тренажёр (контракт `window.PubApps.register`) |
| `app.css` | стили; каждое правило начинается с `.app-paticcasamuppada` |
| `data_ru.json`, `data_thai.json` | 12 звеньев, фразы, финал, все подписи интерфейса |
| `check.js` | проверка данных при сборке (12 звеньев по порядку, одинаковые `id` в языках, облако 1–6, ровно 8 фраз, все подписи) |

## Как работает

- Колода из 12 звеньев вперемешку. Лицевая сторона — название; оборот — номер звена, жизнь, оба соседа,
  смысл и облако под заглушками («показать всё» / «скрыть всё»); мини-колесо показывает место звена, только когда открыт номер.
- «Помню» — звено уходит из колоды, экран «Звено запомнено» (кнопка «Продолжить» включается через 0,7 с).
  «Не помню» — звено в конец очереди, плашка «… вернётся позже» внизу следующей карточки (около 2,5 с). Последнее звено — сразу финал.
- Карта круга: 12 звеньев, дуги трёх жизней, переходы между жизнями, место разрыва цепи (7 → 8);
  нажатие на звено открывает его оборот для просмотра.
- Финал: точки загораются по порядку цепи → кольцо → Колесо Дхаммы (как `img/icon.svg`) →
  «Круг пройден», цитата, «Маджхима-никая, сутта 28». Кнопки «Перечитать публикацию», «Пройти заново».
- Сброс — только через подтверждение («Начать круг заново?»), в том числе по «Пройти заново».
- Прогресс: `localStorage`, ключ `terms-app:paticcasamuppada:progress:<язык>` →
  `{ "v": <версия данных>, "remembered": [id…], "updated": <мс> }`; другая версия или повреждённая
  запись — тихий сброс. Без `localStorage` тренажёр работает без сохранения.
- Карточка в статье: мини-колесо (запомненные звенья горят), «запомнено N из 12», «Запустить» / «Продолжить».
- События GoatCounter: `app/paticcasamuppada/launch` (запуск), `app/paticcasamuppada/done` (пройден круг).
- `prefers-reduced-motion: reduce` — без анимаций, только смена экранов.
- Тайская версия: тайские цифры во всех числах, шрифты Noto Sans Thai / Noto Serif Thai.
