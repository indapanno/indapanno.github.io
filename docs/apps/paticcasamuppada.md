# Приложение `paticcasamuppada` — тренажёр 12 звеньев

Тренажёр для запоминания цепи взаимозависимого возникновения (paṭiccasamuppāda) к публикациям
`vzaimozavisimoe-vozniknovenie` (RU) и `patitchasamupbat` (TH). Встраивается обогатителем «Приложение»:

```html
<div data-widget="app" data-app="paticcasamuppada"></div>
```

Пометка в черновике: `[приложение: paticcasamuppada]`. Как устроен обогатитель — `docs/for-researchers/ru.md`,
раздел «Обогатители публикаций» (№ 16).

## Файлы

`publications/apps/paticcasamuppada/`:

| Файл | Что это |
|---|---|
| `app.json` | имя, версия, название и описание карточки на двух языках, текст «без JavaScript» |
| `app.js` | тренажёр (контракт `window.PubApps.register`) |
| `app.css` | стили; каждое правило начинается с `.app-paticcasamuppada` |
| `data_ru.json`, `data_thai.json` | 12 звеньев, фразы, финал, все подписи интерфейса |
| `check.js` | проверка данных при сборке (12 звеньев по порядку, одинаковые `id` в языках, облако 1–6, ровно 8 фраз, все подписи) |

## Как работает

- Колода из 12 звеньев вперемешку. Лицевой стороны нет (с 2.0): карточка сразу открывается оборотом —
  название звена, под ним на первых 30 новых карточках подсказка «Вспомним скрытое поле, затем нажмём на него и сверимся.»;
  номер звена, жизнь, оба соседа, смысл и облако — под заглушками («показать всё» / «скрыть всё»); мини-колесо — под своей заглушкой, открывается отдельно от номера; открытое колесо открывает карту круга.
- «Помню» — звено уходит из колоды, экран «Звено запомнено» (кнопка «Продолжить» включается через 0,7 с).
  «Не помню» — звено в конец очереди, плашка «**название** снова появится позже» на следующей карточке (около 2,5 с) — с 2.3 над кнопкой «показать всё / скрыть всё» и всегда в видимой части карточки. Последнее звено — сразу финал.
- Карта круга: 12 звеньев, дуги трёх жизней, переходы между жизнями, место разрыва цепи (7 → 8);
  нажатие на звено открывает его оборот для просмотра. Открывается с мини-колеса на карточке и (с 2.1) со счётчика
  «осталось N из 12 ›» в шапке — с любого экрана: карточка, «Звено запомнено», финал.
- Что запомнено (с 2.1): на карте запомненные звенья залиты цветом своей жизни и отмечены галочкой ✓, незапомненные —
  обводка; под заголовком «● запомнено N · ○ ещё учим M». Экранный диктор слышит статус в подписи звена
  («Звено 1: авиджжа — запомнено»). Запомненное звено, открытое с карты, — с меткой «✓ запомнено» в шапке и кнопкой
  «Вернуть в колоду»: звено возвращается в колоду (в конец очереди), остальные отметки не трогаются, плашка
  «**название** снова в колоде» на карте. Без подтверждения — шаг лёгкий и обратимый. Незапомненное звено — без метки и кнопки.
- Финал: точки загораются по порядку цепи → кольцо → Колесо Дхаммы (как `img/icon.svg`) →
  «Круг пройден», цитата, «Маджхима-никая, сутта 28». Кнопки «Перечитать публикацию», «Пройти заново».
- Сброс — только через подтверждение («Начать круг заново?»), в том числе по «Пройти заново».
- Прогресс: `localStorage`, ключ `terms-app:paticcasamuppada:progress:<язык>` →
  `{ "v": <версия данных при записи>, "remembered": [id…], "updated": <мс> }`. **Прогресс переживает обновления:**
  версия в записи не проверяется; звенья, которых нет в данных, тихо пропускаются, остальные сохраняются
  (запись переписывается очищенной, с текущей версией). Стирается только испорченная запись (не объект или без
  `remembered`). Без `localStorage` тренажёр работает без сохранения.
- Подсказка: счётчик показов `terms-app:paticcasamuppada:hint-seen` (число, общий для обоих языков). Считается только
  новая карточка из колоды, не возврат с карты и не листание соседей. После 30 показов подсказка не выводится.
  Обновления и «Начать круг заново» счётчик не сбрасывают.
- Карточка в статье (с 2.3 меняется вместе с практикой читателя):
  - ещё не начали — колесо без отметок, название, описание, «Запустить»;
  - начали — описание скрыто (`compact` в ответе `status`); в центре колеса крупное зелёное число запомненных, запомненные
    звенья горят зелёным; строка «запомнено **N** из 12» (число зелёным) и под ней «занимались сегодня / вчера / N дней назад»
    (по полю `updated` записи прогресса; без даты строка не выводится); кнопка «Продолжить»;
  - круг пройден — колесо целиком зелёное, «Круг пройден», кнопка «Открыть».
  Общий запуск (`js/app-launcher.js`) понимает в ответе `status` поля `node` (оформленный текст строки), `compact` (скрыть
  описание) и `button` (своя надпись на кнопке); приложения без этих полей работают как раньше.
- События GoatCounter: `app/paticcasamuppada/launch` (запуск), `app/paticcasamuppada/done` (пройден круг).
- `prefers-reduced-motion: reduce` — без анимаций, только смена экранов.
- Тайская версия: тайские цифры во всех числах, шрифты Noto Sans Thai / Noto Serif Thai.

Мелкие правки — 1.1, изменение механики — 2.0. **Любая правка тренажёра — новая версия, без исключений**: номер виден
в подвале всех экранов и сбрасывает кэш браузера (`app.js?v=<версия>`). Прогресс читателей при этом не теряется.
Версия меняется в `app.json` и в обоих `data_*.json` одновременно (сборка проверяет совпадение).
