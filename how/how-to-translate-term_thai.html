พบคำศัพท์ที่ยังไม่มีคำแปลในภาษาที่คุณต้องการใช่ไหม? นี่คือวิธีแปลภายใน 5 นาที — โดยไม่ต้องมีความรู้พิเศษ

เมนู
    นำทางคำศัพท์ / วิธีแปลคำศัพท์

    ขั้นตอน

    1. เปิดไฟล์คำศัพท์บน GitHub ในภาษาต้นทางที่คุณจะแปล — เช่น dukkha_ru.json — แล้วคัดลอกเนื้อหาทั้งหมด
    2. เปิด AI ฟรี (เช่น Claude หรือ ChatGPT) แล้ววางข้อความที่คัดลอกมา พร้อมคำขอ: «แปล JSON นี้เป็นภาษาไทย รักษาโครงสร้างและ key เดิมไว้ แปลเฉพาะค่าข้อความ และเปลี่ยน key term_ru เป็น term_thai»
    3. ตรวจสอบผลลัพธ์ — โดยเฉพาะคำศัพท์บาลี (โดยทั่วไปจะไม่แปล แต่คงไว้ตามเดิมหรือถอดเสียง)
    4. บน GitHub ในโฟลเดอร์ json กดปุ่ม Fork เพื่อสร้างสำเนา repository ของคุณ (ต้องมีบัญชี GitHub ฟรี)
    5. ในสำเนาของคุณ สร้างไฟล์ชื่อเดียวกับคำศัพท์ แต่เปลี่ยนนามสกุลภาษา — เช่น dukkha_thai.json — แล้ววางข้อความที่แปลแล้วลงไป
    6. บันทึกไฟล์ — GitHub จะแสดงปุ่ม Create pull request ให้เอง
    7. รอการตรวจสอบ หลังจากได้รับการอนุมัติ คำแปลจะปรากฏบนเว็บไซต์

    สำหรับผู้ดูแลเว็บไซต์

    ตรวจสอบ Pull Request ความถูกต้องของ JSON และโครงสร้าง คัดลอก HTML template ของการ์ดในชื่อเดียวกัน (หากยังไม่มี)

    สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมของชุมชน «มรรคสู่พระอรหันต» OpenChat บนแอปพลิเคชันไลน์ (LINE). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
