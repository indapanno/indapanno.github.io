Как добавить термин

Сначала проверьте поиском выше на этой странице, что такого термина ещё нет — возможно, он уже добавлен.

  1. Перейдите по ссылке github.com/indapanno/indapanno.github.io/fork и нажмите Create fork — это создаст вашу личную копию репозитория, в которой можно свободно редактировать файлы, не затрагивая основной сайт. Нужен бесплатный аккаунт GitHub — если его нет, регистрация занимает пару минут.
  2. Введите термин в поле ниже и нажмите «Скопировать промт» — готовый промт с вашим термином окажется в буфере обмена. Вставьте его в любой бесплатный ИИ (например, Claude, ChatGPT или Gemini) и получите готовый JSON. Скопируйте весь ответ ИИ целиком, включая фигурные скобки в начале и конце.

    Затем вставьте промт в любой бесплатный ИИ и получите готовый JSON.

  3. Проверьте JSON: вставьте ответ ИИ на странице «Проверка JSON» и нажмите «Проверить». Если найдены ошибки, скопируйте их список кнопкой и отправьте тому же ИИ с просьбой исправить JSON, затем проверьте снова. Переходите к следующему шагу, когда появится «JSON корректен ✓».
  4. В своей копии репозитория (не в оригинальном indapanno/indapanno.github.io!) откройте папку json, нажмите Add file → Create new file.
  5. В поле имени файла введите значение ключа "id" из полученного JSON, плюс окончание _ru.json (латиницей, без пробелов). Например, если в JSON написано "id": "karuna" — имя файла: karuna_ru.json.
  6. В большое текстовое поле ниже вставьте весь JSON целиком, без изменений. (Если удобнее — можно вместо этого сохранить JSON файлом на компьютере и загрузить через Add file → Upload files, результат тот же.)
  7. Нажмите зелёную кнопку Commit changes... в правом верхнем углу страницы — откроется отдельное окно.
  8. В открывшемся окне поле Commit message можно не менять. ⚠️ Обязательно переключите нижний вариант на «Create a new branch for this commit and start a pull request» — по умолчанию выбран неверный вариант «Commit directly to the main branch», который отправит файл прямо в вашу копию и не предложит изменения основному сайту. После переключения заголовок окна сменится на «Propose changes» и появится поле с именем новой ветки (например, ваш_ник-patch-1) — его менять не нужно. Нажмите зелёную кнопку Propose changes внизу окна.
  9. Откроется страница «Comparing changes». Обычно вверху НЕ будет строки base repository — только base: main и compare: <имя вашей ветки>. Это нормально: так выглядит сравнение внутри вашей собственной копии. Нажмите ссылку compare across forks сразу под заголовком «Comparing changes» — появится дополнительный выбор base repository. Откройте его и выберите indapanno/indapanno.github.io (изначально там отмечена ваша копия) — поля head repository и compare трогать не нужно, они уже верные. Если строка base repository: indapanno/indapanno.github.io отображается сразу, без клика по ссылке — просто переходите к следующему шагу.
  10. Нажмите зелёную кнопку Create pull request, при желании добавьте описание и нажмите её ещё раз на следующей странице.
  11. Дождитесь проверки администратором. После одобрения термин появится в навигаторе.
