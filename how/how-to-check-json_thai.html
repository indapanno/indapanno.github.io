ตรวจสอบ JSON ก่อนส่ง

วาง JSON ที่ AI สร้างให้ แล้วกด «ตรวจสอบ» ระบบจะตรวจจับภาษาของการ์ด (รัสเซียหรือไทย) โดยอัตโนมัติ ตรวจเฉพาะรูปแบบ ไม่ตรวจข้อเท็จจริง — ผู้ดูแลยังคงตรวจเนื้อหา

ในข้อความ ลำดับของรายการนับเริ่มจาก 1 เช่น sources[1] คือแหล่งอ้างอิงแรก

สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมของชุมชน «มรรคสู่พระอรหันต» OpenChat บนแอปพลิเคชันไลน์ (LINE). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
