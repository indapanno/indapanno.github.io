วิธีเพิ่มคำศัพท์

ก่อนอื่นตรวจสอบด้วยการค้นหาด้านบนของหน้านี้ว่ายังไม่มีคำศัพท์นี้อยู่แล้ว

  1. ไปที่ลิงก์ github.com/indapanno/indapanno.github.io/fork แล้วกด Create fork เพื่อสร้างสำเนาส่วนตัวของ repository ที่คุณสามารถแก้ไขได้อย่างอิสระโดยไม่กระทบเว็บไซต์หลัก ต้องมีบัญชี GitHub ฟรี — หากยังไม่มี การสมัครใช้เวลาเพียงไม่กี่นาที
  2. กรอกคำศัพท์ในช่องด้านล่าง แล้วกด «คัดลอกพรอมต์» — พรอมต์พร้อมคำศัพท์ของคุณจะถูกคัดลอกไปยังคลิปบอร์ด นำไปวางใน AI ฟรีตัวใดก็ได้ (เช่น Claude, ChatGPT หรือ Gemini) แล้วคุณจะได้ JSON ที่พร้อมใช้งาน คัดลอกคำตอบของ AI ทั้งหมด รวมทั้งวงเล็บปีกกาต้นและท้าย

    จากนั้นนำพรอมต์ไปวางใน AI ฟรีตัวใดก็ได้ แล้วคุณจะได้ JSON ที่พร้อมใช้งาน

  3. ตรวจสอบ JSON: วางคำตอบของ AI ในหน้า «ตรวจสอบ JSON» แล้วกด «ตรวจสอบ» หากพบข้อผิดพลาด ให้กดคัดลอกรายการข้อผิดพลาด ส่งให้ AI ตัวเดิมเพื่อแก้ไข JSON แล้วตรวจสอบอีกครั้ง ไปขั้นตอนถัดไปเมื่อขึ้นข้อความ «JSON ถูกต้อง ✓»
  4. ในสำเนา repository ของคุณ (ไม่ใช่ indapanno/indapanno.github.io ต้นฉบับ!) เปิดโฟลเดอร์ json แล้วกด Add file → Create new file
  5. ในช่องชื่อไฟล์ ให้ใส่ค่าของคีย์ "id" จาก JSON ที่ได้รับ ตามด้วย _thai.json (ตัวอักษรละติน ไม่มีช่องว่าง) เช่น หาก JSON เขียนว่า "id": "karuna" — ชื่อไฟล์คือ karuna_thai.json
  6. วาง JSON ทั้งหมดลงในช่องข้อความใหญ่ด้านล่าง โดยไม่แก้ไข (หากสะดวกกว่า สามารถบันทึก JSON เป็นไฟล์ในเครื่องแล้วอัปโหลดผ่าน Add file → Upload files แทนได้ ผลลัพธ์เหมือนกัน)
  7. กดปุ่มสีเขียว Commit changes... ที่มุมขวาบนของหน้า — จะมีหน้าต่างแยกเปิดขึ้นมา
  8. ในหน้าต่างที่เปิดขึ้นมา ช่อง Commit message ไม่ต้องแก้ไข ⚠️ ต้องเลือกตัวเลือกด้านล่างเป็น «Create a new branch for this commit and start a pull request» ให้แน่ใจ — ค่าเริ่มต้นคือ «Commit directly to the main branch» ซึ่งผิด เพราะจะส่งไฟล์เข้าสำเนาของคุณโดยตรง ไม่เสนอการเปลี่ยนแปลงไปยังเว็บไซต์หลัก หลังจากเลือกแล้ว หัวข้อหน้าต่างจะเปลี่ยนเป็น «Propose changes» และจะมีช่องชื่อบรานช์ใหม่ปรากฏขึ้น (เช่น ชื่อผู้ใช้-patch-1) — ไม่ต้องแก้ไข จากนั้นกดปุ่มสีเขียว Propose changes ด้านล่างหน้าต่าง
  9. จะเปิดหน้า «Comparing changes» โดยทั่วไปด้านบนจะไม่มีบรรทัด base repository — มีเพียง base: main และ compare: <ชื่อบรานช์ของคุณ> เท่านั้น ซึ่งเป็นเรื่องปกติ: นี่คือการเปรียบเทียบภายในสำเนาของคุณเอง กดลิงก์ compare across forks ที่อยู่ใต้หัวข้อ «Comparing changes» — จะมีตัวเลือก base repository เพิ่มขึ้นมา เปิดมันแล้วเลือก indapanno/indapanno.github.io (ค่าเริ่มต้นจะเป็นสำเนาของคุณเอง) — ส่วน head repository และ compare ไม่ต้องแก้ไข ถูกต้องอยู่แล้ว หากบรรทัด base repository: indapanno/indapanno.github.io แสดงขึ้นมาทันทีโดยไม่ต้องกดลิงก์ — ข้ามขั้นตอนนี้ไปได้เลย
  10. กดปุ่มสีเขียว Create pull request เพิ่มคำอธิบายได้ตามต้องการ แล้วกดปุ่มเดิมอีกครั้งในหน้าถัดไป
  11. รอการตรวจสอบจากผู้ดูแล หลังจากได้รับการอนุมัติ คำศัพท์จะปรากฏในตัวนำทาง

สร้างโดยพระอินทปัญโญ จากวัดป่าถ้ำวนนิมิต จังหวัดนครนายก ประเทศไทย เดือนกันยายน ๒๐๒๖. ตัวนำทางประวัติคำศัพท์บาลีเป็นเนื้อหาเสริมของชุมชน «มรรคสู่พระอรหันต» OpenChat บนแอปพลิเคชันไลน์ (LINE). จำนวนคำศัพท์ในตัวนำทาง: …. เวอร์ชันเว็บแอปพลิเคชัน: ๑.๐.๐. สำหรับนักวิจัยและนักพัฒนา. จำนวนการเข้าชม: 0.
